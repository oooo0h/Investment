# 净值一键更新

在项目根目录双击 `一键更新持仓基金净值.cmd`，按顺序调用 `基金/持仓基金/` 下每个基金文件夹中的 `更新本基金净值.cmd`，目前共7只（含004103）。单独双击子脚本只更新所在持仓基金。观察基金不建立子入口，也不在更新范围内。完成后窗口保留结果，按任意键关闭。移动整个项目后入口仍通过相对路径寻找工具。

CMD窗口显示当前基金、总进度、已存条数、最新公布日期、新增及修订条数、失败原因和最终汇总。单只失败会继续处理其他基金，最终返回失败退出码。

全部日志、原始接口响应、校验结果、Excel预览、暂存与回滚备份统一保存在 `临时文件/净值更新/<运行时间>/`。父任务有总日志和汇总，每只基金有独立日志。该目录不进入GitHub。

更新保持每只基金根目录的唯一工作簿：七只持仓基金（四只权益基金、三只债基）为 `<代码>_交易记录.xlsx` 的 `全部历史净值` 工作表，观察基金暂为 `<代码>_全部历史净值.xlsx`。更新保留完整历史，补齐上次更新后的缺口并复核已有末尾5个净值日期。管理人公布的历史修订会记录证据后更新；源数据缺失旧日期、条数不一致或原值消失时停止该基金更新。休市日及尚未公布的日期不造记录。没有变化时不改写主档。

`270023` 沿用广发基金官网人民币A接口，其他基金沿用各自现有天天基金主档。官网主序列之外的待复核记录仍在独立工作表，不合并进官网历史。工具只读取公开净值主档，不读取交易记录和账户文件。

先在临时目录生成并逐行复读Excel，再替换JSON、CSV与Excel，并刷新全部、六基金和四基金当前入口。更新有系统文件锁，重复启动时明确退出；写入失败回滚，意外关窗则下次运行先恢复备份。Excel被占用时可关闭该表后重试。

工作簿整本哈希会因网页登记交易或Excel保存而变化；净值主档校验以JSON、CSV及工作簿内的`全部历史净值`工作表为准。整本哈希不同但净值表核验通过时继续更新，并保留`交易记录`工作表；生成与发布阶段仍用启动时的整本哈希防止并发覆盖，避免把正在登记的交易改掉。

2026-10-21修复清理临时目录后找不到 `@oai/artifact-tool` 的问题。Windows设备自动检测当前用户的Codex捆绑环境，其次使用系统Python/Node.js；表格依赖优先使用显式配置，再查找当前用户的Codex捆绑依赖、临时目录共享入口和标准项目依赖。无需固定用户名或盘符，也不依赖临时目录链接一直存在。

另一台设备可通过环境变量配置运行环境（路径可含空格）：

- `FUND_NAV_PYTHON`：Python解释器路径，需具备 `openpyxl`、`pypdf`。
- `FUND_NAV_NODE`：Node.js可执行文件路径，或系统可识别的命令名。
- `FUND_NAV_NODE_MODULES`：包含 `@oai/artifact-tool` 的 `node_modules` 目录，填写目录而非包文件路径。

仅复制项目文件不会自动安装这些运行依赖；未配置Codex的Windows设备需先配置上述环境。缺少表格依赖时显示配置提示并保留原文件。不自动安装软件，不将共享依赖复制进正式项目或Git。

终端检查示例（只查询，不改写正式文件）：

```text
一键更新持仓基金净值.cmd --no-pause --check-only
```

正式文件的GitHub同步按项目既定完整目录流程执行。净值入口不自行提交或推送，避免把用户其他正在编辑的文件一并提交。

## 晚间自动更新（Windows 计划任务）

2026-10-22新增。任务名 `基金账本-晚间净值自动更新`，每天 20:00、21:30、23:00 检查一次。它不启动浏览器，只在本地网站服务未运行时调用本页的一键更新；如果本地网站服务正在运行，则跳过，由网站内部 19:00 晚间轮询负责。2026-10-23起，Windows 登录后 20 秒会自动在后台启动本地网站，因此该计划任务通常会发现服务已运行并跳过；这是预期行为。

- 安装/重装：`powershell -NoProfile -ExecutionPolicy Bypass -File "工具脚本\安装晚间净值自动更新任务.ps1"`
- 删除：给上述命令加 `-Uninstall`
- 只读检查（不改正式净值文件）：`powershell -NoProfile -ExecutionPolicy Bypass -File "工具脚本\晚间净值自动更新.ps1" -CheckOnly`
- 强制在服务运行时也更新：给上述命令加 `-Force`
- 日志：`临时文件\净值更新\晚间自动更新.log`；每次更新仍有独立目录
- 睡眠/关机错过触发：任务设置 StartWhenAvailable，恢复后补跑；包装脚本有互斥量，更新器另有文件锁
- 任务只更新公开净值主档、CSV、`全部历史净值` 工作表和当前入口；不读取账户金额、不提交 Git、不发布 Pages

实现原因：网站内部的 19:00 轮询只在 `启动网站.cmd` / `serve.mjs` 进程运行时有效；电脑晚间未开网站时，计划任务提供兜底。两者同时存在时不会重复改写主档。

- 运行条件：当前 Windows 用户保持登录（锁屏可以；注销/关机时不运行）。关机或睡眠错过触发时，任务设置 StartWhenAvailable 在恢复后补跑一次。
