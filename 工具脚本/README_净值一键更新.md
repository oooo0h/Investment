# 净值一键更新

在项目根目录双击 `一键更新持仓基金净值.cmd`，按顺序调用 `基金/持仓基金/` 下每个基金文件夹中的 `更新本基金净值.cmd`，目前共6只。单独双击子脚本只更新所在持仓基金。观察基金不建立子入口，也不在更新范围内。完成后窗口保留结果，按任意键关闭。根目录指本项目 `数据分析/`，移动整个项目后入口仍通过相对路径寻找工具。

CMD窗口显示当前基金、总进度、已存条数、最新公布日期、新增及修订条数、失败原因和最终汇总。单只失败会继续处理其他基金，最终返回失败退出码。

全部日志、原始接口响应、校验结果、Excel预览、暂存与回滚备份统一保存在 `临时文件/净值更新/<运行时间>/`。父任务有总日志和汇总，每只基金有独立日志。该目录不进入GitHub。

更新保持每只基金根目录的唯一 `<代码>_全部历史净值.xlsx`，保留完整历史，补齐上次更新后的缺口并复核已有末尾5个净值日期。管理人公布的历史修订会记录证据后更新；源数据缺失旧日期、条数不一致或原值消失时停止该基金更新。休市日及尚未公布的日期不造记录。没有变化时不改写主档。

`270023` 沿用广发基金官网人民币A接口，其他基金沿用各自现有天天基金主档。官网主序列之外的待复核记录仍在独立工作表，不合并进官网历史。工具只读取公开净值主档，不读取交易记录和账户文件。

先在临时目录生成并逐行复读Excel，再替换JSON、CSV与Excel，并刷新全部、六基金和四基金当前入口。更新有系统文件锁，重复启动时明确退出；写入失败回滚，意外关窗则下次运行先恢复备份。Excel被占用时可关闭该表后重试。运行依赖本机Codex捆绑Python、Node.js与临时文件内的共享表格依赖入口；不自动安装软件。

终端检查示例（只查询，不改写正式文件）：

```text
一键更新持仓基金净值.cmd --no-pause --check-only
```

正式文件的GitHub同步按项目既定完整目录流程执行。净值入口不自行提交或推送，避免把用户其他正在编辑的文件一并提交。
