# 融资与市场 · A股双纵轴曲线图

纯 HTML、CSS、JavaScript 与本地 Apache ECharts 6.0.0。无需安装前端依赖或构建，数据来自公开历史行情，未使用模拟数据。

## 使用

- **直接查看**：双击 `index.html`，可离线查看保存的数据和使用全部图表交互。
- **联网更新**：在本目录运行 `npm start`，或双击 `启动图表.cmd`，访问 [本地图表](http://127.0.0.1:5173)，点击「更新数据」。需要 Node.js 与 PowerShell；服务器只监听本机。
- **命令行更新**：运行 `npm run refresh`。程序按北京时间排除16:00之前的当日日线，融资和成交额按交易日期对齐，校验失败时不覆盖已发布的数据快照。
- **校验**：运行 `npm test`。

## 图表交互

- 四个指标卡片即图例，点击或通过键盘 Enter/空格切换曲线。
- 融资资金比例独占右轴；三类指数共用左轴。
- 纵轴范围仅取**当前显示曲线、当前时间区间**的有效值，再添加留白。隐藏融资线时右轴也隐藏；仅显示融资线时左轴隐藏；全部隐藏时可一键恢复。
- 支持快捷区间、自定义起止日期、底部时间选框拖动、图内拖动平移、Ctrl + 滚轮缩放及重置。日期选择支持单个交易日。
- 默认累计涨跌幅，三个指数以2024年首个共同交易日收盘点位为固定基准；变更时间区间不改变基准。也可切换原始点位。
- 悬停显示同一天的数值、原始点位和融资比例计算分子/分母。数据明细视图提供逐日原始点位。

融资分子采用东方财富 `RPTA_RZRQ_LSDB` 中 `H_RZMRE + S_RZMRE`（元），不使用包含北交所的 `TOTAL_RZMRE`。这是沪深交易所融资交易汇总，包含其融资标的证券（含ETF等），并非仅股票标的的融资买入额。分母采用上证A股（000002）与深证A股（399107）的成交金额；搜狐原始列单位为万元，乘10,000转换为元。两者均不计北交所。

三个指数都是价格指数，不包含分红再投资。双轴分别缩放，曲线交点不代表数值相等，图表不计算或声称因果关系。

初始快照为2024-01-02至2026-09-14，共655个交易日。最新完整日期、获取时间和缺失天数都由数据自动生成并在页面显示。融资信息通常延后公布，未对缺失数据补零或插值。

## 文件

- `index.html` / `styles.css` / `app.js`：前端页面、样式与交互。
- `chart-core.js`：归一化、时间索引与纵轴范围算法。
- `data/market-data.js` / `market-data.json`：可离线复用的数据快照。
- `data/raw/`：公开数据源的原始响应，可重新下载，已忽略版本控制。
- `scripts/refresh-data.ps1` / `prepare-data.cjs`：公开数据下载、分页、合并与校验。
- `server.cjs`：静态预览与固定的本地更新接口，不接受任意命令或文件路径。
- `vendor/echarts.min.js`：Apache ECharts 6.0.0，保留原版权许可声明。

公开接口可能变更或暂时不可访问。页面不会把更新失败伪装成最新数据；仍可使用已保存快照，并在状态栏看到更新失败原因。
