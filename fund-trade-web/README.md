本地服务现已包含19:00后的净值轮询，QDII以前一交易日为目标，非QDII以当天交易日为目标；未更新基金每3分钟重试，全部达标后停止当晚轮询。云端页面不运行该任务。另有 Windows 计划任务 `基金账本-晚间净值自动更新`，每天 20:00、21:30、23:00 在本地服务未运行时直接更新公开净值；服务运行时由内部轮询负责。Windows 登录后 20 秒还有 `基金账本-登录自动启动网站` 在后台启动本地服务，不自动打开浏览器；服务已在运行时复用。交易日历范围、区间盈亏、四基金持仓分布、电脑侧边菜单和债基订单兼容说明见[本地晚间净值轮询](docs/local-evening-nav.md)。

2026-10-21新增电脑端本地模式“同步交易记录”：侧边菜单 `+` 按钮登记买入、卖出、转换。2026-10-22改为全屏双列卡片：每列显示自由现金流和七只基金，滚轮/点击选择，选中卡片不透明，其余按距离淡化；左右两张卡片自动推断买入、卖出或转换，中间箭头可交换两侧，下单日期通过日历点选，保存按钮在箭头下方，点击空白处关闭。手续费按各基金目录的买入/卖出截图执行：买入按金额档位与净申购公式，卖出按成交日期起算的 FIFO 持有天数，转换收转出赎回费加转入申购补差费。详见[网页登记与同步交易记录](docs/transaction-sync.md)。
