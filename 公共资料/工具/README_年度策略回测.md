# 年度策略研究的本地阅读与复算

这些脚本只使用公开基金净值和假设的归一化预算，不读取账户持仓、交易记录或截图。研究覆盖270023、005698、016701及用于固定参数敏感性的016702。历史候选与限制见[跨基金汇总](../投资研究/270023_005698_016701_年度策略历史候选汇总_2026-10-16.md)。

## 阅读已经保存的结果

Markdown报告、PNG研究图、JSON结果和CSV净值可以直接从仓库阅读。它们不依赖原作者的Windows目录，也不需要安装Codex或运行脚本。报告中的本地资料链接相对于报告文件所在目录；JSON的资料指针通常相对于仓库根目录，路径分隔符使用`/`。

研究目录中的PNG是公开净值和假设预算的研究图。用户平台规则截图仅在本地保存，公开说明中标为“本地规则材料未上传”；可通过其中的基金管理人公开文件链接进行交叉核对。

## Python依赖

公共会计引擎`annual_threshold_backtest.py`和研究框架`annual_threshold_study.py`使用Python标准库。基金级入口通过自身文件位置定位仓库，无须设置本机绝对路径。使用支持脚本语法的Python 3环境，建议Python 3.10及以上。

部分附加功能需要：

| 依赖 | 使用范围 |
| --- | --- |
| `numpy` | 270023有限网格搜索和相关筛选脚本 |
| `matplotlib` | `render_*.py`研究图 |
| `pypdf` | 005698定期报告下载后的PDF抽取和分析 |

需要这些功能时，在独立环境中安装：

```sh
python -m pip install numpy matplotlib pypdf
```

绘图脚本优先采用Windows现有微软雅黑文件。该文件不存在时使用字体候选列表，不再因缺少Windows路径直接退出。Linux等环境如需正确显示中文，应配置可用中文字体，例如`Noto Sans CJK SC`；仅有默认西文字体时，图中文字可能缺字。字体变化不影响JSON数值结果。

## 脚本分工与历史文件保护

| 入口 | 用途 |
| --- | --- |
| [公共会计引擎](annual_threshold_backtest.py) | FIFO、费用、现金流、TWR及风险指标 |
| [公共研究框架](annual_threshold_study.py) | 注册参数网格、时序选择和固定参数敏感性 |
| `基金/270023_广发全球精选股票_QDII_人民币A/scripts/` | 原规则、规则搜索、年度投入比较及报告绘图 |
| `基金/005698_华夏全球科技先锋混合_QDII_A人民币/scripts/` | 华夏年度研究与报告绘图 |
| `基金/016701_银华海外数字经济量化选股混合发起_QDII_A/scripts/` | 银华A类研究与报告绘图 |
| `基金/016702_银华海外数字经济量化选股混合发起_QDII_C/scripts/` | 读取A类已选参数，只做C类敏感性 |

表内基金路径相对于仓库根目录。运行入口前先检查脚本的输入、输出及已有文件保护逻辑。部分入口会重新写结果，部分研究会拒绝覆盖已注册预设。仅阅读报告无需重跑任何模型。

需要做新实验时，使用单独工作副本和新的实验名称，保留原始净值、原始响应、预设、锁定文件及历史主结果。C类结果记录了A类主结果的SHA-256，不能为修链接而重写A类主结果。不要把技术重跑产生的时间、路径或文件哈希变化解释为新投资证据。

复算历史研究应使用报告注明日期和SHA-256对应的已归档净值。联网下载取得的是运行时可见的数据，不能自动替代历史冻结输入。[公开净值下载器](download_holding_nav.py)及[银华公开净值下载器](download_yinhua_public_nav.py)使用Python标准库；广发管理人净值下载器使用Node.js内置`fetch`，需Node.js 18及以上。上述网络来源的可达性、证书和返回口径可能变化。

## CSV作者工具的特殊依赖

[持仓净值CSV作者脚本](export_holding_nav_csv.mjs)和[银华CSV作者脚本](export_yinhua_nav_csv.mjs)使用Codex配置的`@oai/artifact-tool`，通过工具目录下`tmp/node_modules`联接解析该依赖。它们适用于已经配置该运行依赖的Codex环境；普通克隆不会自带此依赖，不能将其当作公开npm包安装步骤。

不上传`node_modules`、Windows联接或本机运行时。需要重新导出时，在获准的Codex环境中配置相同依赖联接并创建临时目录，再按表格工具要求生成和核验。已经归档的CSV可直接使用；Python回测读取JSON，不依赖这些CSV作者工具。

## 公开原始证据

各基金`历史净值/原始数据/`保存公开接口响应。部分管理人PDF、官网HTML和全页核验摘要位于对应基金`临时资料/`，具体路径及哈希见数据与费率核验JSON。这些公开来源文件支持核验，不应仅因目录名含“临时资料”而一并删除。

账户截图、交易分析目录和用户平台规则图片属于另外的本地资料范围，不是本套公开回测的输入。银华官网未完成独立全量核验等限制仍以研究报告和核验JSON中的说明为准。
