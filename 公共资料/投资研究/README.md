# 投资研究缓存

本目录用于复用已核验的基金资料和组合结论，减少重复联网查询。

## 隐私规则

- 用户于 2026-09-16 再次明确金额保密；项目根目录 `AGENTS.md` 与 `项目整理规则.md` 已同步该规则。
- 不在本目录保存任何具体持仓金额、成本金额、盈亏金额或资产合计。
- 对话中默认不显示上述金额。
- 同样隐藏现金余额和申赎金额；进度、工具输出、图表及预览也必须遵守。新文件只保存近似比例，不保存可反推出金额的精确份额与净值组合。
- 即使用户主动要求显示，也必须先询问一次；只有用户在下一条消息再次明确确认，才可在当次回复中显示。
- 一次确认仅对当次回复有效。
- 分析可以使用比例、风险贡献和高/中/低仓位描述。

## 复用与刷新规则

1. 优先读取 `portfolio-state.json` 和 `fund-research.md`，不要重复查询仍在有效期内的资料。
2. 基金底层持仓以最新已披露定期报告为准。出现新季报、年报或基金经理变更时才刷新。
3. 指数估值、波动率及行业权重属于时变数据；当用户询问“现在、最新、今天”或缓存超过30天时刷新。
4. 基金费率、限购、申赎状态和赎回费属于时变规则；涉及交易决定时必须重新核验基金公司公告。
5. 宏观事件和市场行情不使用本缓存代替实时查询。
6. 每次用户提供新截图或明确交易完成后，更新组合状态及 `updated_at`，但仍不落盘具体金额。
