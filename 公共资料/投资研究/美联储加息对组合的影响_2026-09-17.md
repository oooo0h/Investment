# 美联储加息对组合的影响

研究日期：2026-09-17，北京时间。性质：事件分析与条件判断，未执行交易或变更定投。仅记录近似比例及收益率，不保存账户金额。

**结论：本次加息对现有基金组合的短期估值环境偏不利，但不能据此推断组合必跌，更不能从25个基点直接换算净值跌幅。主要风险是两只主动QDII集中承担科技、半导体及成长估值风险；人民币计价下的汇率变化可能缓冲或放大波动，境内短债提供有限缓冲，黄金不是确定性对冲。**

组合既有偏好为持有3—5年、接受较大回撤。一次加息不足以否定这个期限内的投资逻辑，但高利率持续时间、企业盈利和集中度仍需一起评估。

**资料口径。**账户依据2026-09-16同步的11只基金记录，截图净值日期未显示，不等于9月17日即时仓位。未计入未经本次确认的历史现金、其他资产及负债。基金底仓复用9月16日已核验的2026年中报，实际持仓日为6月30日，披露日为8月31日；下文穿透比例只是旧底仓与近期基金权重的静态映射。国富基金份额类别仍待确认。账户比例四舍五入，分类汇总与逐项相加可能有尾差。

**本次政策事实及其含义。**美联储于美国时间9月16日、北京时间9月17日凌晨宣布加息25个基点，将目标区间升至3.75%—4.00%。声明认为经济仍稳健扩张、通胀偏高。本次动作针对通胀，并不能单凭声明认定经济已经衰退。[美联储声明](https://www.federalreserve.gov/newsevents/pressreleases/monetary20260916a.htm)

9月经济预测中，2026年末及2027年末政策利率中位数均为4.1%，高于6月的3.8%及3.6%。这是官员对合适政策路径的判断，不是承诺，也不是市场隐含概率。对组合更有持续影响的变量是利率预期是否继续上修，以及高利率是否持续更久。[美联储9月预测](https://www.federalreserve.gov/monetarypolicy/fomcprojtabl20260916.htm)

资产价格会提前反映预期。宣布加息的当天不一定是冲击最大的一天；影响还来自未来路径、风险溢价及盈利信息。本次未提取会议前后的利率期货完整序列，不声称已定价某个精确比例，也不把市场全部涨跌归因于加息。[美联储研究：政策对股票市场的影响](https://www.federalreserve.gov/econres/feds/the-effect-of-the-federal-reserve-on-the-stock-market-magnitudes-channels-and-shocks.htm)

**持仓逐项影响。**以下是条件性研究判断，不是测算得到的利率敏感系数。

| 持仓 | 组合占比约 | 高利率持续或超预期收紧的压力 | 可能的缓冲与反向因素 |
|---|---:|---|---|
| 广发全球精选A，270023 | 48% | 最大单一基金仓位；科技估值、半导体需求及港股融资环境均可能受压 | 企业盈利继续增长、基金调仓、相关外币对人民币升值 |
| 华夏全球科技先锋A，005698 | 27% | 科技主题集中；披露的每日杠杆产品增加半导体波动与路径风险 | 科技资本开支与盈利超预期；上涨趋势中杠杆也可能放大收益 |
| 国富全球科技互联，类别待确认；招商纳指联接A，019547 | 合计约2% | 继续承担科技成长风险，对前两只不构成可靠对冲 | 盈利增长与外汇折算可能缓冲；目前对组合总变化的影响较小 |
| 广发中证500增强A，009608；易方达A500联接A，022459 | 合计约2% | 全球风险偏好下降、外需和汇率变化可能传导 | 国内政策与盈利周期可能不同步；人民币走弱对部分出口企业有利 |
| 永赢先进制造A，018124；高端装备A，015789 | 合计约2% | 成长估值和制造景气风险；不能因属于A股就视为避险 | 国内产业需求和政策支持可能抵消外部冲击，但需看实际公司盈利 |
| 华安黄金联接A，000216 | 2% | 实际利率上升、美元走强通常形成压力 | 通胀担忧、避险需求及人民币走弱可能支持人民币金价 |
| 安悦超短债C，006663；广发1—3年国开债C，006485 | 合计约17% | 国内收益率若上升，存量债券价格承压；超短债另有信用及流动性风险 | 主要受中国利率和资金面驱动；短期限降低利率敏感性，国内宽松可支持债券 |

两只最大基金合计约75%，偏股基金产品约81%。这是产品市值分类，不是穿透后的股票仓位。广发更需要关注的是对账户的影响规模；华夏更需要关注的是主题和产品结构。未估计两只基金的实时beta，不能将上述判断写成确定的涨跌排名。

**底层的共同风险比基金名称更重要。**按中报，广发与华夏直接信息技术股票分别约占各自净值67%和60%。映射到本次组合，仅这部分已约占49%；尚未计入其他基金、杠杆产品及行业分类之外的科技相关公司。这些资产可能同时受到估值下降、风险偏好下降和资本开支预期转弱影响。[已核验的组合研究](./组合客观评估与优化_2026-09-16.md)

同一映射下，两只大基金的直接内地股票约占账户组合18%、香港股票约12%、美国股票约27%。这些是交易市场分类，既不是公司收入地区，也不是完整货币敞口。两只基金并非全部投资美股，不能将约77%的QDII产品仓位直接当作美元敞口。日韩直接股票也会受到全球半导体周期及本币汇率影响；地理分散不一定带来产业风险分散。

华夏中报另披露三倍半导体ETF约占基金净值8.6%，每日两倍海力士产品约1.0%，两者合计对应账户资本约3%。这不表示华夏整只基金有三倍杠杆。每日重置产品的多日收益取决于走势、波动、费用与复利，不能将半导体区间收益简单乘三；震荡回撤可能使持有体验弱于简单倍数预期，持续上涨也可能产生有利的复利路径。[SOXL发行人说明](https://www.direxion.com/product/daily-semiconductor-bull-bear-3x-etfs)

**股票的压力和支持要同时看。**在盈利预期不变时，较高的无风险利率和风险溢价会压低投资者愿意支付的估值，远期盈利占比高的公司通常更敏感。如果高利率进一步削弱融资、订单和终端需求，就会叠加盈利压力。但现金充裕、盈利增长强的公司，与依赖持续融资的公司承受的冲击不同；强劲需求也可能同时带来加息和企业收入增长。因此，“科技股受估值压力”并不等于“所有科技股必跌”。[美联储货币政策传导说明](https://www.federalreserve.gov/monetarypolicy/monetary-policy-what-are-its-goals-how-does-it-work.htm)

港股部分还需关注联系汇率下的港元利率环境，尤其是融资依赖高、盈利较远的成长公司。香港金管局9月17日公开讲话称基准利率上调至4.25%。这不等于所有银行贷款利率或拆息即时等幅上调。[金管局讲话转载](https://ebs.publicnow.com/view/DE75CB5027388D05B2A894E551410A1B50907176)

**汇率可以缓冲，但不能保证。**对没有汇率对冲的美元资产，忽略费用等因素：

人民币收益率 =（1 + 美元资产收益率）×（1 + 美元对人民币升值率）− 1。

例如，美元资产下跌15%、美元对人民币升值5%，人民币收益约为−10.8%。汇率减少了跌幅，仍没有抵消全部下跌。这是一个假设算例，不是本次已发生的行情，也不是对组合全部资产的适用公式。基金还有人民币、港元、日元等资产、现金、衍生品及潜在对冲安排，准确影响需最新货币净敞口。

加息也不保证美元升值。汇率同时反映两国相对利率、经济增长、风险偏好和事先定价；若美元上涨不足或人民币反而升值，相关境外资产的人民币收益可能受到额外拖累。[美联储关于紧缩与汇率的研究](https://www.federalreserve.gov/econres/notes/feds-notes/monetary-policy-and-exchange-rates-during-the-global-tightening-20240510.html)

**境内债券不能套用美债结论。**你的两只债券基金主要对应人民币债券，不是美元长债。安悦超短债约占组合12%，国开债指数约4%；二者合并独立四舍五入约17%。如果国内经济、政策与流动性支持较低利率，它们可能保持稳定或上涨；若国内收益率因汇率约束、供给或资金紧张上行，也会阶段性承压。美联储加息25个基点，不能直接代入这两只基金的价格变动。

债券价格的一阶近似关系是：价格变化率≈−修正久期×收益率变化。这里的收益率必须是基金所持人民币债券的收益率，不能替换成美国政策利率。没有最新组合久期与信用利差数据，本次不提供伪精确估值。国内利率上升时，存量价格承压与后续再投资收益改善也需要分开看。超短债并不保本。[安悦超短债官方产品页](https://www.efunds.com.cn/fund/006663.shtml)

**黄金没有固定方向，当前仓位也难以承担大幅对冲。**人民币黄金同时受到国际金价、美元兑人民币及境内外价差影响。实际利率上升可能压低黄金吸引力，但通胀和地缘风险、央行与其他买盘可能抵消；实际利率取决于名义利率与通胀预期，不等同于一次名义加息。[世界黄金协会对利率和美元单变量模型的研究](https://www.gold.org/goldhub/research/qaurum-vs-us-real-rates-and-dollar-model)

**用可复核的敏感性代替跌幅预测。**以下只计算权重乘假设人民币净值变化；其他基金不变、不交易、不再平衡。基金净值变化已包含其汇率和杠杆影响，不再另行叠加。表中收益率没有统一的实现期限，不构成概率预测。

| 单独假设 | 组合收益影响约 |
|---|---:|
| 广发净值下跌10% | −4.8个百分点 |
| 华夏净值下跌10% | −2.7个百分点 |
| 两只大基金同时下跌10% | −7.5个百分点 |
| 黄金基金净值上涨20% | +0.4个百分点 |
| 两只债券基金净值均上涨2% | +0.3个百分点 |

前两行与第三行是不同算例，不能重复相加。计算使用状态文件中的四舍五入权重。债券主要通过不跟随股票大跌而降低组合波动，不需要靠大幅上涨才有作用；但当前黄金和债券也不能确保抵消权益损失。

**后续可能出现的几条路径。**这是条件分析，不给缺乏证据的概率，也不预设对应净值目标。

| 后续条件 | 对组合的推论 |
|---|---|
| 加息接近尾声，通胀回落，科技盈利继续增长 | 估值压力可能逐步被盈利消化，科技仓位可恢复甚至继续上涨；单次加息不否定长期回报 |
| 通胀反复，市场持续上调利率路径，同时盈利预期下修 | 对现有组合最不利的组合条件之一，两只大基金可能一起承压；美元升值仅是可能缓冲 |
| 经济明显转弱，之后转向降息 | 初期仍可能因盈利与风险偏好下修而跌；降息也不是股票立即上涨的保证 |
| 国内宽松、海外偏紧 | 人民币债券可能提供缓冲；A股表现取决于国内盈利和政策效果，仍非确定性对冲 |

**实际决策含义。**不宜仅凭一次加息机械清仓，也不能把“长期持有”当作不审视结构的理由。在没有新的目标权重决定前，优先审视两只基金合计约75%的集中度，以及新增投入是否继续扩大同一科技风险。仓位调整应依据愿意承受的回撤、用款期限、最新底仓及交易成本，而不是猜测单次会议方向。本次未核验逐笔持有期和实时赎回费，不据此生成具体交易指令。

现有人民币短债仍有配置价值，不应因为“加息利空债券”就一概卖出。增加纳指、日韩半导体或另一只科技基金，也未必减少共同产业风险。若后续目标是显著压低全市场下跌时的回撤，需要同时评估总权益比例，仅换基金名称并不足够；降低集中度也可能在科技继续领涨时减少收益。

日常最有用的观察对象是：美国中长期实际利率与预期政策路径、核心通胀趋势、主要科技公司的订单/利润/资本开支、美元兑人民币、国内短端利率以及基金新披露的持仓。美国短期政策利率、中长期收益率及实际利率不必同幅同向变化。本次未创建监控或自动交易。

场外QDII存在净值披露和跨市场时差，应按实际净值日期评估影响，不能把平台某天显示的全部涨跌归因于那天公布的政策。3—5年的期限允许跨越部分短期波动，但不保证最终盈利；如果届时有确定用款，应随着用款日期接近另行匹配资产期限。
